# Top Talkers

A starter repo for a side-by-side experiment: the same app, built from the same prompt by Opus 5.5 at max effort in one shot, and by Opus 5.5 at medium effort using Matt Pocock's skills (https://github.com/mattpocock/skills) and GitHub Spec Kit (https://github.com/github/spec-kit).

`fixtures/flows.jsonl` holds 400 real NetFlow records. Every address in it has been replaced with an address from the documentation ranges (RFC 5737 and RFC 3849).

Copy `.env.example` to `.env` and fill it in. Never commit `.env`.
